# SplitSecond

Every Millisecond Matters.

SplitSecond is a daily precision challenge where players attempt to stop a hidden timer as close as possible to five daily target times.

## Core Gameplay

- Five targets generated daily
- Same targets for all players
- Hidden timer
- One completed run per day
- Players are ranked by lowest total error

## Scoring

Error = Absolute Difference Between Target Time and Actual Time

Total Error = Sum of All Five Attempt Errors

Lower Total Error ranks higher.
