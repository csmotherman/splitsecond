# MVP Scope

## Included

- Anonymous accounts
- Daily challenge generation
- Hidden timer
- Five daily targets
- Results screen
- Daily leaderboard
- Percentile calculation
- Player profiles
- Core statistics

## Not Included

- Friends
- Teams
- Achievements
- Mobile app
- Paid subscriptions
- Advanced anti-cheat
- Seasonal events

Goal: launch a playable daily game as quickly as possible.
