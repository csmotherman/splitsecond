# MVP Scope

The MVP should prove one thing:

Can people play a hidden timer challenge, enjoy it, and come back tomorrow?

Anything that does not help answer that question should wait.

---

# Included

- Daily challenge generation
- Same five targets for all players
- Hidden timer gameplay
- Five daily attempts
- Results screen
- Save daily submission
- Save individual attempts
- One completed challenge per player per day
- Daily leaderboard
- Basic profile stats

---

# Basic Profile Stats

The MVP profile only needs:

- Career Average Error
- Days Played
- Current Streak
- Longest Streak
- Perfect Timers
- Best Daily Score
- Attempts

---

# Not Included

- Ranks
- MMR
- Percentile as a core stat
- Full achievements
- Friends
- Teams
- Head-to-head
- Mobile app
- Paid subscriptions
- Advanced anti-cheat
- Seasonal events

---

# Post-MVP Priorities

Add only after the core game has real usage:

1. Shareable result cards
2. Better profiles
3. Weekly and monthly leaderboards
4. Milestones
5. Ranks/MMR after enough score data exists
6. Head-to-head challenges

---

# MVP Success Criteria

The MVP is successful if users:

- Complete the full five-target challenge
- Understand their result
- Check the leaderboard
- Return the next day
- Share their score with someone else
