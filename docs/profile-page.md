# Profile Page

The profile page should be clean, visual, and easy to understand in less than five seconds.

The profile should not feel like a spreadsheet. It should highlight identity, consistency, and precision.

---

# Hero Section

Displayed at the top of the profile.

- Username
- Profile Picture or Initials
- Career Average Error
- Days Played
- Current Streak

Purpose:

Show how good and active the player is immediately.

---

# Core Stats

Displayed directly below the Hero Section.

- Perfect Timers
- Longest Streak
- Best Daily Score
- Attempts

Purpose:

Show precision, consistency, peak performance, and experience.

---

# Recent Activity

Show the last 10 completed daily challenges.

Each row should include:

- Date
- Total Error
- Perfect Timers Earned
- Completed Time

Do not show percentile in recent activity for MVP because daily percentile changes as more users submit.

---

# Career Stats

Career stats should be grouped into expandable sections.

## Performance

- Career Average Error
- Best Daily Score
- Best Week
- Best Month

## Precision

- Perfect Timers
- Timers Within 0.05
- Timers Within 0.10
- Timers Within 0.25
- Precision Percentage

## Participation

- Days Played
- Attempts
- Current Streak
- Longest Streak

## Competition

These statistics should be tracked but may be hidden until traffic is high enough.

- Top 10 Finishes
- Top 100 Finishes
- First Place Finishes

---

# Milestones

Milestones should be added after the MVP if users show retention.

Potential milestones:

- First Perfect Timer
- 10 Perfect Timers
- 50 Perfect Timers
- 100 Perfect Timers
- 7 Day Streak
- 30 Day Streak
- 100 Days Played
- 365 Days Played

---

# Future Competitive Identity

Ranks, MMR, grades, and percentiles should not be part of the MVP profile.

They should be designed later using real player data.

For MVP, the profile identity is built around:

- Career Average Error
- Days Played
- Current Streak
- Perfect Timers
